# Better LOL Chat - Buff your post-game flame!

A plugin to improve League of Legends **post-game chat**. 

![image](https://github.com/user-attachments/assets/09b0e05e-ba3a-4d89-b7c7-30ef91405036)

## Features

- Display champion names alongside or instead of player names
- Champion icons in chat
- Color messages by team (also fixes a client bug that marks all players as enemy team)
- Larger chat window
- Compact champion icon and level displayed next to runes so chat doesn't cover them
- Automatically open chat
- Sticky chat window
- Pause auto-scroll while you read older messages
- Customizable chat colors
- Hide `player joined the lobby` messages
- More pronounced darkened overlay for players who left chat
- Show champion names in honor tooltips
- Full options menu to toggle features on or off

## Install

### 1. Install Pengu Loader

Install [Pengu Loader](https://pengu.lol/) first. Pengu is an open source utility that allows packages like better-lol-chat to inject code into the LOL client.

### 2. Add the plugin

Use the installer, or extract the zip yourself.

#### Via One-click Installer

1. Download [blc-install-1.0.bat](https://github.com/12boost/better-lol-chat/releases/download/v1.0/blc-install-1.0.bat) and run it.
2. Restart League client (`Ctrl + R`).

#### Or Extract it yourself

1. Download [better-lol-chat.zip](https://github.com/12boost/better-lol-chat/releases/latest/download/better-lol-chat.zip).
2. Extract the `better-lol-chat` folder into Pengu's `plugins` folder. Default location is `C:\Program Files\Pengu Loader\plugins\`.
3. Restart League client (`Ctrl + R`).

That's it! Enjoy flaming your teammates with a superior chat experience! 

If you want to verify the plugin is running: in the client, press `Ctrl + Shift + I` and open the console. It should show `[better-lol-chat]` followed by the version.

## Demo

Chat too quiet? You can inject sample messages (only you will see them) by typing `/demo` or `/sample` in the post-game chat. 

## Updates

When an update is released, you'll get a notification right in your chat window with a changelist and a link to download.
